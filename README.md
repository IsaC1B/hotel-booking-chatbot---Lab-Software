# hotel-booking-Chatbot ---Lab-Software
Sistema web desarrollado para la asignatura Laboratorio de Software, orientado a la gestión integrada de reservas de alojamiento y alimentación en un hotel, incorporando un chatbot para la atención inicial y orientación de los huéspedes

## Descripción del proyecto
El proyecto consiste en desarrollar un chatbot conversacional especializado en la atención de huéspedes y la gestión inicial de solicitudes hoteleras. El chatbot permitirá a los usuarios realizar consultas sobre alojamiento, alimentación, servicios disponibles, horarios, tarifas, políticas del hotel y proceso de reserva mediante lenguaje natural.

El proyecto no contempla el desarrollo de una página web completa de reservas. El chatbot será el componente central y podrá comunicarse con una base de datos, una API o un servicio simulado que proporcione información sobre habitaciones, disponibilidad y servicios hoteleros.

De esta manera, el proyecto se enfoca en estudiar y desarrollar la interacción conversacional, la identificación de intenciones, la extracción de datos relevantes y la generación de respuestas útiles para mejorar la atención al cliente.

##Planteamiento del problema 
En muchos establecimientos hoteleros, la atención de los huéspedes se realiza mediante llamadas telefónicas, mensajes en redes sociales, correos electrónicos o aplicaciones de mensajería. Esta situación puede generar tiempos de respuesta elevados, saturación del personal, repetición de preguntas frecuentes, información fragmentada y dificultades para atender varias solicitudes simultáneamente.

Además, los usuarios suelen necesitar información sobre:

- Disponibilidad de habitaciones.

- Tarifas y tipos de alojamiento.

- Fechas de entrada y salida.

- Número de huéspedes.

- Servicios de alimentación.

- Horarios de atención.

- Políticas de cancelación.

- Servicios adicionales.

Cuando estas consultas son atendidas exclusivamente por personal humano, el hotel puede presentar demoras y una mayor carga operativa.

Por lo tanto, se propone desarrollar un chatbot especializado que permita automatizar la atención inicial, responder preguntas frecuentes, recopilar los datos necesarios para una reserva y orientar al usuario hacia el siguiente paso del proceso.

## Objetivo general 
Desarrollar un chatbot conversacional especializado en servicios hoteleros que permita atender consultas frecuentes, identificar las necesidades de los usuarios y gestionar inicialmente solicitudes relacionadas con alojamiento y alimentación.

##Objetivos específicos
1. Analizar las necesidades de atención y las consultas frecuentes que realizan los huéspedes en un establecimiento hotelero.

2. Identificar las principales intenciones conversacionales relacionadas con alojamiento, alimentación, disponibilidad, tarifas y reservas.

3. Diseñar la arquitectura conversacional del chatbot, incluyendo flujos de diálogo, respuestas, validaciones y manejo de conversaciones incompletas.

4. Desarrollar un chatbot capaz de interpretar mensajes de los usuarios y responder de acuerdo con las intenciones identificadas.

5. Integrar el chatbot con una base de datos, API o servicio simulado que proporcione información sobre habitaciones, servicios y disponibilidad.

6. Implementar un mecanismo para recopilar datos básicos de una solicitud de reserva, como fechas, cantidad de huéspedes, tipo de habitación y servicios adicionales.

7. Evaluar el desempeño del chatbot mediante métricas de precisión de intención, completitud de solicitudes, tiempo de respuesta y satisfacción del usuario.
